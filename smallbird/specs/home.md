| 펼치기(제자리) | 모든 기기에서 모달 없이 같은 입력창이 **아래 끝을 고정한 채 위로 커져** 히어로·문구 위를 덮습니다. 입력창 자리는 비워 두어 **카드는 펼침·축소와 관계없이 제자리**입니다. 높이는 입력창 아래 끝에서 본문 안쪽 위까지이되 **보이는 영역(스크롤 영역 높이·`visualViewport` 높이에서 위아래 여백을 뺀 값)을 넘지 않아** 키보드가 떠 있어도 화면을 벗어나지 않습니다(Android는 `interactive-widget=resizes-content`로 스크롤 영역이 줄고, iOS는 `visualViewport`만 줄어듦). 레이아웃이 바뀌면 `ResizeObserver`, iOS 키보드는 `visualViewport`의 `resize`로 높이만 다시 잽니다(scroll 이벤트·스크롤 위치는 건드리지 않음). 같은 textarea라 포커스·한글 조합이 유지됩니다. 펼침은 눌렀을 때 바로 반응하도록 `cubic-bezier(0.22, 1, 0.36, 1)` 곡선 360ms로, 한 프레임 앞선 지점에서 시작하고(클릭 뒤 렌더에 쓴 시간과 진행 0인 첫 프레임을 가림), 축소는 `cubic-bezier(0.32, 0.72, 0, 1)` 곡선 280ms로 높이가 전환됩니다. 아이콘은 크로스페이드합니다. 축소하는 동안에도 입력창은 `absolute`로 아래 끝을 고정한 채 줄어들고(전환이 끝난 뒤 일반 흐름으로 복귀), 입력 영역도 함께 줄어 안쪽이 먼저 튀지 않으며, 히어로·문구·카드는 움직이지 않습니다(펼치기 전과 접은 뒤 입력창 높이가 다르면 폼 높이만 함께 전환). 높이가 `auto`↔고정값이라 CSS transition이 아니라 Web Animations를 쓰고, 모션 줄이기를 켜면 즉시 바뀝니다. **펼치기 버튼은 `mousedown`의 기본 동작을 막아 포커스를 가져가지 못하게 해** 모바일 키보드가 내려가지 않습니다(동작은 `click`). 키보드가 열린 태블릿·모바일은 펼치지 않아도 입력창이 자리를 차지하지 않고(기본 142px 자리 유지) 위로 커져 카드를 덮습니다 |

## 5. 후속 작업에 적용할 결정 (이번 범위 아님)

사용자에게 받은 답변입니다. 해당 메뉴·API·화면이 생길 때 적용합니다.

**메뉴·LNB 정책**: 공통 셸이라 [main.md](main.md) "LNB 메뉴 구성과 권한"으로 옮겼습니다(2026-10-20 사용자 지시).

**카드 연결 시**
- "캠페인 등록/운영" → 캠페인 현황, "요금 안내" → 마이페이지 > 구독입니다. 비로그인 알럿은 인플루언서 추천·캠페인 등록/운영에 적용했고(§3), 요금 안내의 비로그인 처리는 디자인팀 지시를 받으면 적용합니다.

**헤더 기능 연결 시 (API 연동 후)**
- **빅버드 머니:** 헤더 "P"는 빅버드 머니입니다. 마우스를 올리면 충전 아이콘(lucide `CirclePlus`)으로 바뀌고, 누르면 마이페이지 > 빅버드 머니 화면으로 갑니다. 세부는 [mypage/money.md](mypage/money.md) §3 "헤더 P 연결".
- **알림:** 항목을 누르면 읽음 처리만 하고 페이지는 이동하지 않습니다. 패널 바깥을 클릭하면 닫힙니다.
- **계정 설정:** 프로필 설정(톱니)은 마이페이지 > 계정 설정으로 갑니다.
- **알림 수신:** FCM 웹푸시를 씁니다.
  - **권한 요청 제안(승인 필요):** 비로그인에게는 요청하지 않습니다. 접속하자마자 권한 창을 띄우지 않고, 로그인 사용자가 처음 알림 패널을 열 때 앱 안 안내 배너를 보여 줍니다. 사용자가 [알림 켜기]를 누를 때만 `Notification.requestPermission()`을 호출합니다. [나중에]를 누르면 일정 기간(예: 14일) 배너를 다시 띄우지 않습니다.
  - **권한 거부·미지원 시:** 다시 묻지 않고 앱 안 알림(벨·패널)만 씁니다. iOS Safari 일반 탭처럼 웹푸시를 지원하지 않는 환경에서는 배너를 띄우지 않습니다.
  - **로그아웃 시:** FCM 토큰을 삭제하고 서버 등록도 해제합니다.
  - `firebase` SDK와 Service Worker 추가는 팀 승인 절차를 따릅니다.
