# i18n 런타임

다국어 런타임의 결정 요약입니다. 작성 규칙은 `.claude/rules/i18n.md`에 있습니다.

## 언어 결정

- 순서: `?lng=` → `localStorage`(`bigbird.lng`) → `navigator.languages` → `ko`. 시작할 때 한 번만 정하고, 언어 전환 UI·변경 함수는 없습니다.
- `?lng=`는 지원 언어일 때만 받아 저장합니다. 잘못된 값은 무시합니다. 한국어로 되돌리려면 `?lng=ko`.
- 브라우저 언어는 언어 부분으로 매칭합니다. `zh*`는 번체를 포함해 `zh-CN`입니다.
- `localStorage` 예외(사생활 보호 모드)는 저장값 없음으로 처리합니다.
- 실제 렌더한 언어를 `<html lang>`에 넣습니다. `index.html`의 기본값은 `ko`입니다.

## 로딩

- `ko`는 번들에 포함하고, 다른 언어는 결정된 언어 파일만 dynamic import합니다. 실패하면 `ko`로 렌더하고 저장값은 그대로 둡니다.
- `main.tsx`는 초기화가 끝난 뒤 렌더합니다(`useSuspense: false`).
- `fallbackLng`는 `ko`. 개발 환경에서는 시작할 때 현재 언어에 빠진 키를, 사용 중에는 `ko`에도 없는 키를 `console.warn`으로 알립니다.

## 배치

- `src/shared/i18n/`: 런타임(`initI18n`, `resolveLanguage`, `useLanguage`), 포맷터(`formatDate`, `formatNumber`), `common` namespace. `i18next`·`react-i18next`는 이 폴더에서만 임포트합니다(ESLint `no-restricted-imports`의 `paths`).
- `src/app/i18n/`: 모든 슬라이스의 `locales/*.json`을 `import.meta.glob`으로 모으고, 언어 결정·폰트 로딩·테스트 초기화(`test-setup.ts`, vitest `setupFiles`)를 맡습니다.
- namespace는 경로에서 정합니다: `src/{layer}/{slice}/locales/{lng}.json` → `{layer}/{slice}`, `src/shared/i18n/locales/` → `common`.

## 타입과 검사

- `pnpm i18n`이 모든 `ko.json`으로 `src/app/i18n/resources.gen.d.ts`(`CustomTypeOptions`)를 생성합니다. 없는 키는 `pnpm typecheck`가 실패합니다.
  - 스펙의 `typeof import("…json")` 대신 `import type x from "…json"` + `typeof x`를 씁니다. 기존 `@typescript-eslint/consistent-type-imports`가 `import()` 타입 표기를 금지하기 때문입니다(설정은 바꾸지 않음).
- `pnpm i18n:check`(`scripts/i18n.mjs`, 의존성 없음) 실패 조건: 4개 언어 파일 누락·지원하지 않는 파일, 언어별 키 구성 불일치(`en`은 `_other`마다 `_one` 추가), 빈 문자열, 허용하지 않은 `locales` 위치, 생성 타입 파일이 최신이 아님. 안 쓰는 키는 검사하지 않습니다.
- 실행 위치: `.gitlab-ci.yml`의 `static` 잡, `.claude/hooks/verify-on-stop.sh`.

## 포맷·날짜 컴포넌트

- `DatePicker` 기본 `formatValue`는 `formatDate`, `Calendar`는 현재 언어의 `react-day-picker` 로케일(`ko`, `enUS`, `ja`, `zhCN`)과 `formatDate` 월 이름, `chart.tsx`는 `formatNumber`. 호출부 props가 우선합니다.
- `pages/ui-preview`의 로케일 고정은 개발 전용이라 그대로 둡니다.

## 폰트

- `ja`: `pretendard-jp`(`Pretendard JP Variable`) CSS를 `ja`일 때만 dynamic import.
- `zh-CN`: Google Fonts Noto Sans SC `<link>`를 `zh-CN`일 때만 삽입.
- `font-family`는 `src/app/styles/index.css`의 `:root:lang(ja)`·`:root:lang(zh-CN)`에서 `--font-family-base`를 바꿉니다. `zh-CN`은 Pretendard → Noto Sans SC → PingFang SC → Microsoft YaHei 순입니다.

## 다국어

- namespace: `common`(닫기·뒤로가기·다시 시도, 불러오는 중·확인 중, 라우트 에러 화면, 비밀번호 보기/숨기기, 소셜 로그인 버튼), `pages/not-found`(파일럿), `pages/welcome`, `pages/find-email-sent`, `pages/cert-success`, `pages/home`, `pages/coming-soon`, `features/search-influencer`, `pages/switch-account`, `features/switch-account`, `widgets/app-shell`, `pages/login`, `features/login`, `features/social-login`, `pages/sns-link`, `pages/find`, `features/find-account`, `pages/expired`, `features/expired-password`, `pages/change-password`, `features/change-password`, `pages/join`, `features/join`, `pages/introduction`, `pages/terms`
- `entities/account`는 문구를 두지 않고 판정 결과(코드)만 돌려줍니다.
- `common`에는 여러 화면이 같이 쓰는 필드명·링크(아이디, 비밀번호, 로그인, 확인, 되돌아가기, 개인정보처리방침, 이용약관, 아이디/비밀번호 찾기, 회원가입)도 둡니다.
- 휴면 만료 법적 고지(`features/login` `error.destroyed`)는 한국어 원문 그대로이고 en·ja·zh-CN은 약관과 같이 Claude 번역본입니다. 법무 검수는 미정입니다.
- 메인 임시 세션 요약의 권한(`authority`)·하위 권한 이름(`subPermissions` 키)은 서버가 주는 코드성 값이라 번역하지 않고 그대로 표시합니다(임시 화면, 대시보드 본문 작업 때 재검토).
- `app` 레이어와 `shared/components`는 `common`만 씁니다. 소셜 로그인 버튼의 제공자 이름은 en·ja·zh-CN에서 로마자 표기(Kakao·Naver·Apple·Google)를 씁니다.
- 약관 본문(`entities/terms`)은 Claude로 일괄 번역한 언어별 파일(`model/content/{lng}.ts`)을 현재 언어에 맞춰 불러옵니다. 한국어 원문이 기준이고 법무 검수는 미정입니다. 용어집 질의는 `docs/glossary-questions.md`에 모읍니다.
- 서비스 고유 용어: `docs/glossary-questions.md`(확정 전까지 한국어 유지). 백엔드 번역 요청: `specs/auth/join.md` "다국어" 절(가입 카테고리 이름, 본인인증 실패 메시지)
