# v2 → v3 마이그레이션 노트

v2(`bigbird-client-fe`)의 동작을 v3로 옮기면서 확정한 결정을 기록합니다.
세션 간 메시지는 대화 기록이 남지 않으므로, 오래 유지할 내용은 반드시 이 파일에 적습니다.

## 작업 규칙

- v2 코드는 **읽기 전용**으로 참조합니다. v2 수정은 v2 세션(`v2-legacy`)에서만 합니다.
- v2 동작이 불명확하면 추측하지 말고 `v2-legacy` 세션에 질문하거나 "미해결 질문"에 적습니다.
- 결정이 나면 바로 아래 표에 한 줄 추가합니다.
