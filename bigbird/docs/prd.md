# bigbird PRD

> 프로젝트 전체의 목적·범위·용어를 정의합니다. 기능 단위 상세는 `specs/<feature>.md`에 둡니다.
> "미정"은 확정되지 않은 항목입니다. 에이전트는 미정 항목을 추측으로 채우지 말고 질문합니다.

## 1. 서비스 개요

bigbird는 **광고주가 자사 상품(서비스)에 적합한 크리에이터(인플루언서)를 빅데이터 분석으로 찾아 매칭해 주는 B2B 서비스**입니다.
이 저장소는 그 서비스의 **광고주용 웹 클라이언트**입니다.

## 2. 사용자

| 구분 | 설명 | 이 프로젝트 포함 여부 |
|---|---|---|
| 광고주 (기업 고객) | 인플루언서를 검색·추천받고 캠페인을 등록하는 주 사용자 | 포함 |
| 비로그인 방문자 | 홈에서 서비스 소개를 보고 문의하거나 검색을 미리 체험하는 사용자 | 포함 |
| 인플루언서 | 캠페인 제안을 받는 크리에이터 | **제외** (이 프로젝트는 광고주 전용) |
| 내부 운영자 | 서비스 관리 | 미정 |

## 3. 환경·공통 요구

- **디바이스:** 반응형 (모바일 + 데스크톱)
- **언어:** 한국어(기본) + 영어. 모든 사용자 노출 문구는 다국어 대상입니다. **i18n 라이브러리를 도입하기로 확정**했습니다. 어떤 라이브러리를 쓸지는 미정이며, 선정 시 `dependencies` 규칙에 따라 사용자 승인을 받습니다.
- **지원 브라우저·접근성 기준:** 미정
- **디자인 원본:** Figma. **API 원본:** OpenAPI 명세 (백엔드 개발 중, 명세 위치 미정 — 나오기 전에는 목 데이터를 사용합니다).

## 4. 사용 시나리오 (예)

스킨케어 신제품을 홍보하려는 광고주가 20대 여성 타깃, 인스타그램 중심으로 인플루언서를 검색하고, 필터로 좁히거나 AI 추천 도우미에게 조건을 말해 추천받은 뒤, 마음에 드는 인플루언서를 즐겨찾기에 담고 캠페인을 제안합니다.

## 5. 기능 목록

### 5.1 홈 · 탐색
- 홈(`/`)은 로그인·비로그인 모두 접근 가능하며 **헤더 형태만 로그인 상태에 따라 달라집니다.**
- 홈의 목적: 서비스 소개, 문의 유입.
- 홈에 인플루언서 검색 화면을 둡니다. 비로그인 방문자에게는 **검색과 결과 목록 일부 미리보기**만 보여 줍니다 (일부의 기준, 상세·전체 열람 시 로그인 유도 방식은 미정).
- 로그인 후 대시보드의 경로와 구성은 미정.

### 5.2 인증
- 소셜 로그인: 카카오, 네이버, 페이스북, 애플, 구글 (목록은 "등"이 붙어 있어 추가 가능성 있음).

### 5.3 구독 · 결제
- 광고주는 플랫폼을 **구독**하여 사용합니다. 구독 결제는 **신용카드**입니다.
- **빅버드 머니:** 플랫폼 내에서 쓰는 머니. 충전은 **무통장 입금**입니다. (사용처, 환불 정책은 미정)

### 5.4 인플루언서 검색 · 추천
- 광고주가 검색할 **인플루언서 플랫폼(예: 인스타그램)을 선택**해 추천받습니다.
- 검색 필터: 팔로워 수, 평균 댓글 작성자 수, 브랜드 지수, 공구 지수, 예상 비용, 평균 조회수 등.
- **AI 추천 도우미 챗봇:** 검색 조건에 맞는 인플루언서를 추천합니다.
- 인플루언서 **상세 페이지:** 스펙을 다양한 차트로 표현하고, 인플루언서가 활동 중인 각 플랫폼의 최근 피드를 받아 보여 줍니다.

### 5.5 즐겨찾기 · 관리
- 인플루언서 즐겨찾기 저장, **즐겨찾기 폴더** 생성.
- 인플루언서 관리 대시보드.

### 5.6 캠페인
- 캠페인 등록: **모집형 / pick형** 중 선택 후 등록.
- 특정 인플루언서에게 캠페인 제안.
- 캠페인 등록·승인·거절에 대한 **알림**.
- 특정 인플루언서와 **채팅**.

## 6. 릴리스 범위

| 단계 | 범위 |
|---|---|
| **MVP (현재)** | **Figma 시안 기준으로 이 프로젝트의 모든 화면을 정적 퍼블리싱**합니다. API 연동 없이 화면 구현 중심이며 목 데이터를 사용합니다. 화면은 한꺼번에 만들지 않고 **단계별로 개발**하며, **홈화면이 첫 단계**입니다. |
| 이후 | API 연동 등 동작 구현. 화면 개발 순서와 연동 순서는 미정 |

- 5장의 기능 목록은 현재 알려진 범위이며 **앞으로 기능이 더 추가될 예정**입니다. 새 기능은 이 문서에 추가한 뒤 `/spec`으로 상세화합니다.

## 7. 용어집

| 용어 | 의미 |
|---|---|
| 광고주 | 상품을 홍보하려는 기업 고객 (이 서비스의 사용자) |
| 인플루언서 / 크리에이터 | 광고 대상이 되는 SNS 콘텐츠 제작자 |
| 빅버드 머니 | 플랫폼 내에서 사용하는 선불형 머니 (무통장 입금으로 충전) |
| 모집형 / pick형 | 캠페인 유형. 구체적 차이와 흐름은 미정 |
| 브랜드 지수 / 공구 지수 | 인플루언서 검색 필터 지표. 산출 기준은 백엔드/기획 확인 필요 |
| 공구 | 공동구매 |

## 8. 미해결 질문

- 브랜드명·제품명 등 함께 쓰는 고유 용어 (현재 없음)
- 모집형/pick형 캠페인의 정의와 차이
- 비로그인 미리보기의 범위 기준
- 로그인 후 대시보드의 경로·구성
- 지원 브라우저, 접근성 기준
- i18n 라이브러리 선정
- OpenAPI 명세 위치
- Figma 파일 링크
- 5장 기능의 출시 우선순위
