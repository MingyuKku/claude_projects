# 성능

먼저 측정하고, 체감되는 문제가 있을 때 최적화합니다. 추측으로 넣은 최적화는 코드 복잡도만 늘립니다.

## 지연 로딩

초기 화면에 필요 없는 무거운 것(리치 텍스트 에디터, 차트 라이브러리, 큰 모달, 라우트 단위 페이지)은 `React.lazy()` + `<Suspense>`로 분리합니다. 기준은 "첫 렌더에 필요한가"입니다.

## 메모이제이션

기본은 쓰지 않는 것입니다. 아래처럼 **리렌더 비용이 실제로 크거나 참조 동일성이 필요한 경우**에만 씁니다.

- `useMemo`: 큰 데이터(수백 건 이상)의 필터·정렬·변환, 또는 `React.memo` 자식에 넘기는 객체 prop.
- `useCallback`: `React.memo` 자식에 넘기는 콜백, 디바운스 핸들러.
- 판단이 애매하면 적용하기 전에 React DevTools Profiler로 확인합니다.

## 이미지

스크롤 아래의 이미지는 `loading="lazy"`로 두고, 레이아웃 이동(CLS)을 막기 위해 `width`/`height`를 지정합니다. 가능하면 WebP/AVIF를 씁니다.
