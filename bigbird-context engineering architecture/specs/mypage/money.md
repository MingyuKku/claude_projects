## 1. 목적과 범위

- 광고주가 플랫폼 안에서 쓰는 빅버드 머니를 **무통장 입금(가상계좌)으로 충전**하고, 충전 내역과 사용 내역(인플루언서 계약 비용, 부가 서비스)을 봅니다. v2 `/mileage`(비즈머니, PG 카드 결제)를 대체합니다.
- API와 목 데이터는 [account.md](account.md) §1 규칙을 따릅니다(공개 API가 충분하면 연결, 아니면 목. 목은 화면 구현 확인용이고 구현이 끝나면 흔적 없이 지움). 사용 내역은 V3 API(`POST /v3/mypage/biz-money/usage`)가 공개돼 있어 응답이 충분하면 연결하고, 잔액·충전 내역·충전 요청·거래 상세는 API가 없어(§7 B-1) 목입니다. 목 단계의 충전 요청은 확인 단계까지 진행하고 마지막에 "준비 중인 기능입니다." 토스트, 값은 바꾸지 않습니다.
- 환불·충전 취소는 시안과 정책이 없어 범위 밖입니다(PRD 미정).
- Master(MASTER·ADMIN)와 **빅버드 머니 권한이 있는 Sub ID**가 들어올 수 있습니다(사용자 답변). 권한이 없는 Sub ID에게 LNB 마이페이지 > 빅버드 머니는 흐리게 비활성입니다([main.md](../main.md) "LNB 메뉴 구성과 권한"). 화면 구성은 Master와 같습니다.

### 시나리오

1. 헤더의 "P {보유 금액}" 또는 LNB 마이페이지 > 빅버드 머니로 들어오면 충전 내역 탭이 열립니다. 보유 빅버드 머니와 충전 안내를 봅니다.
2. "충전하기"로 충전 패널을 열고 금액을 입력(또는 빠른 금액)한 뒤 "{금액}원 충전하기"를 누르면 충전 요청이 접수되고, 충전 상세 내역에 "대기 중" 건이 생깁니다. 가상계좌 정보는 그 건의 거래 상세에서 봅니다.
3. 입금이 확인되면 그 건이 "결제 완료"가 되고 보유 금액이 늘어납니다. 기한 안에 입금하지 않으면 "결제 취소"가 됩니다.
4. 사용 내역 탭에서 캠페인별 차감 내역과 사용 후 잔액을 봅니다.

## 4. 배치와 Public API

- `pages/mypage-money`: `MyPageMoneyPage`(탭·세그먼트·쿼리 소유, 셸).
- `entities/bigbird-money`: 보유 금액 뷰모델과 훅 `useBigbirdMoneyBalance()`(잔액 API 전까지 목, 헤더는 목 값을 쓰지 않음). 헤더(`widgets/app-shell`)와 이 페이지가 함께 씁니다. 충전 상태 배지(`ChargeStatusBadge`).
- `features/charge-bigbird-money`: 충전 패널(`ChargePanel`), 금액 규칙 `lib`(최소·한도·빠른 금액 더하기).
- `features/bigbird-money-history`: 충전 상세 내역·거래 상세(`ChargeHistory`, `ChargeDetail`), 사용 상세 내역·사용 상세(`UsageHistory`, `UsageDetail`).
- 결제 내역과 같은 목록 구조(툴바·TAB·MO 필터 화면·MO 카드 리스트·페이지네이션)는 [subscribe.md](subscribe.md) §4의 공통 컴포넌트 검토와 함께 정합니다.
- `shared/config/routes.ts`에 `mypageMoney: "/mypage/money"`. 헤더 P 버튼 연결은 `widgets/app-shell`.

## 5. 데이터 흐름의 예외

- 사용 내역(`UsageRecord`)은 공개 API를 표준 흐름(Zod → 트랜스포머 → SWR)으로 연결합니다. 캠페인 값이 없으면 `"-"`, 금액은 부호 포함, `entrySize` 기본값 5라 페이지 크기 10을 명시합니다([docs/mypage-api.md](../../docs/mypage-api.md) §2).
- API가 없는 잔액·충전 내역·거래 상세는 목 단계라 뷰모델(`BigbirdMoneyBalance`, `ChargeRecord`, `ChargeDetail`)만 둡니다.
- 입금 상태·결제 수단은 서버 코드값으로 받아 배지 색·번역 키에 매핑해야 합니다. 코드 체계 확인(§7 B-5) 전까지 목의 임시 코드(`paid`·`pending`·`canceled`)로 둡니다.
- 헤더 보유 금액은 이 페이지와 같은 훅을 씁니다. API 연동 후 충전 완료 시점에 두 곳이 같이 갱신되도록 같은 SWR 키를 씁니다.
